## Stack

- Next.js 16
- Tailwind CSS v4
- shadcn/ui

## Featured

- Sectioned portfolio layout
- Supports `Light` and `Dark` themes
- Keyboard-first command menu — `Ctrl + K` | `⌘ + K`
- SEO optimized ([JSON-LD schema](https://json-ld.org), sitemap, robots)
- Latest Next.js 16 practices — Cache Components, Instant Navigations,…
- Installable as PWA

## Content

Centralized document system powered by MDX:

- Unified MDX pages for blog posts
- Raw `.md` endpoints for AI readability
- Syntax highlighting with code blocks
- Dynamic OG images for rich link previews
- PDF resume generation using markdown
